Roblox Starter Pack - Instructions
----------------------------------
This package contains starter project folders for multiple Roblox game types.
Each folder contains Lua scripts (ModuleScripts, Server scripts, LocalScripts) and README notes.

How to use:
1. Open Roblox Studio and create a new Place.
2. Use the Explorer to create the folder structure corresponding to the scripts (ServerScriptService, StarterGui, Workspace, etc.).
3. For each .lua file in this package, create the corresponding script type in Studio (Script, LocalScript, ModuleScript) and paste the file contents.
4. Follow per-folder README instructions to wire up RemoteEvents, models, and UI assets.
5. Test in Play and Publish your game.

Note: It's not possible for me to create native .rbxlx files here. These scripts are ready to be pasted into Roblox Studio to build playable templates quickly.
